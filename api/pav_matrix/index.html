    PavMatrix

    pavvis.pav_matrix.PavMatrix

    Constructor

    The PavMatrix() class is the core data structure behind pavvis. By default, all that is required to generate it is a pav.csv and accompanying metadata.csv file.

    File formats

    For more information on how these input files should be structured, see the concepts page.

    pavvis.pav_matrix.PavMatrix.__init__(matrix_path, metadata_path, soft_core_min=0.95, dispensable_min=0.15, private_min=0.0)

    Load and validate a PAV matrix with associated sample metadata.

    Parameters:

    Name Type Description Default
    matrix_path str | Path

    Path to the PAV matrix CSV. Genes must be rows (unique index), samples must be columns (unique headers), values must be 0 or 1.

    		 required
    metadata_path str | Path

    Path to the metadata CSV. Samples must be rows (index must match PAV matrix column headers exactly).

    		 required
    soft_core_min float

    Minimum presence frequency for soft core genes (inclusive). Defaults to 0.95.

    		 0.95
    dispensable_min float

    Minimum presence frequency for dispensable genes (inclusive). Defaults to 0.15.

    		 0.15
    private_min float

    Minimum presence frequency for private genes (exclusive lower bound — genes at exactly this frequency are excluded). Defaults to 0.0.

    		 0.0

    Raises:

    Type Description
    FileNotFoundError

    If either file path does not exist.
    ValueError

    If sample IDs do not match between files, if any PAV value is not 0 or 1, if any cell is blank, or if thresholds are invalid.

    UMAP

    Uniform Manifold Approximation Projection (UMAP) is a dimensionality reduction technique that is used to visualise high-dimensional data. In the context of PAV, it can help gain insight into the relationships between samples through similarity in PAV profiles. Generating UMAP embeddings can be done by calling the compute_umap() method. This is not automatically called on initial construction of new PavMatrix() objects, as it can be computationally intensive, particularly for large datasets.

    pavvis.pav_matrix.PavMatrix.compute_umap(n_neighbors=15, min_dist=0.1, metric='jaccard', random_state=None)

    Compute a 3D UMAP embedding of the samples and cache it on this object.

    Always computes 3 components so the result can be used for both 2D and 3D plots without recomputing. The embedding is computed on the transposed PAV matrix (samples × genes). Re-calling with the same parameters returns the cached result immediately. Re-calling with different parameters recomputes and overwrites the cache.

    Parameters:

    Name Type Description Default
    n_neighbors int

    UMAP n_neighbors parameter. Controls local vs global structure. Defaults to 15.

    		 15
    min_dist float

    UMAP min_dist parameter. Controls how tightly points are packed. Defaults to 0.1.

    		 0.1
    metric str

    Distance metric passed to UMAP. Defaults to 'jaccard', which ignores shared absences and is appropriate for binary PAV data.

    		 'jaccard'
    random_state int | None

    Random seed for reproducibility. Defaults to None.

    		 None

    Returns:

    Type Description
    PavMatrix

    self, so calls can be chained: pm.compute_umap().plot...
